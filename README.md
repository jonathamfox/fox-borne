# Fox Borne

Jogo de ação 2D de rolagem lateral, sombrio e gótico, para jogar no navegador.

**Jogar:** https://jonathamfox.github.io/fox-borne/

No celular, jogue com o aparelho deitado. Controles no teclado: A/D andar, Espaço pular, J golpe, K golpe forte, L rolar, I escudo, Q frasco, E usar, Esc pausa.

Música: "Horror Suspense Tune", de Alex Morgan.
